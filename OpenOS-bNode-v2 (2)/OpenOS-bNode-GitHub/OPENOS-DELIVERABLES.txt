PROJECT OVERVIEW
================================================================================
OpenOS/bNode is a privacy-first, performance-optimized Linux operating system
with a beautiful glassmorphic UI, pre-installed developer tools, and zero
tracking. Built on a hardened Linux kernel with Rust-based system components.

BUILD INSTRUCTIONS
================================================================================

Option 1: Build from Source (Ubuntu 22.04 LTS)
  $ sudo apt-get install build-essential debootstrap xorriso git
  $ git clone https://github.com/openos-bnode/os.git
  $ cd os
  $ sudo bash build-openos.sh
  └── Output: openos-bnode.iso (build time: 30-60 minutes)

Option 2: Docker Build
  $ docker build -f Dockerfile.openos -t openos-bnode:1.0 .
  $ docker run -it openos-bnode:1.0 bash
  └── Output: Docker image (build time: 10-20 minutes)

Option 3: Download Pre-built ISO
  $ wget https://releases.openos-bnode.dev/openos-bnode-1.0.0.iso
  $ sha256sum -c openos-bnode-1.0.0.iso.sha256
  └── Ready to write to USB or boot in VM

QUICK START
================================================================================

1. Create Bootable USB:
   $ sudo dd if=openos-bnode-1.0.0.iso of=/dev/sdX bs=4M && sync

2. Boot from USB and follow installer

3. Post-installation:
   $ sudo apt-get update && sudo apt-get upgrade
   $ sudo hostnamectl set-hostname openos-bnode
   $ sudo ufw enable

4. Start developing:
   $ code &
   $ brave &
   $ docker run -it ubuntu bash
