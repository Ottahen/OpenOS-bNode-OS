## 🚀 **INSTALLATION METHODS**

### **Method 1: USB Installation**

```bash
# 1. Download ISO
wget https://releases.openos-bnode.dev/v2.0/openos-bnode-v2.0.iso

# 2. Create bootable USB
sudo dd if=openos-bnode-v2.0.iso of=/dev/sdX bs=4M status=progress

# 3. Boot from USB
# 4. Follow installation wizard
# 5. All 70+ apps auto-install
```

### **Method 2: Docker**

```bash
# 1. Build Docker image
docker build -f Dockerfile -t openos-bnode:2.0 .

# 2. Run container
docker run -it openos-bnode:2.0 bash

# 3. All tools available in container
```

### **Method 3: Virtual Machine**

```bash
# 1. Download VM image
wget https://releases.openos-bnode.dev/v2.0/openos-bnode-v2.0.qcow2

# 2. Create VM
qemu-system-x86_64 -hda openos-bnode-v2.0.qcow2 -m 4G

# 3. Boot and enjoy
```

### **Method 4: Cloud Deployment**

```bash
# AWS
aws ec2 run-instances --image-id ami-openos-v2.0 --instance-type t3.medium

# Azure
az vm create --resource-group myResourceGroup --name openos-vm --image openos-bnode-v2.0

# DigitalOcean
doctl compute droplet create openos-bnode --image openos-bnode-v2.0
```

## 🔐 **SECURITY & PRIVACY SETUP**

### **Initial Security Configuration**

```bash
# 1. Update system
sudo apt update && sudo apt upgrade -y

# 2. Enable firewall
sudo ufw enable

# 3. Configure firewall rules
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp  # SSH
sudo ufw allow 80/tcp  # HTTP
sudo ufw allow 443/tcp # HTTPS

# 4. Start antivirus
sudo systemctl start clamav-daemon

# 5. Enable automatic updates
sudo apt install unattended-upgrades
sudo dpkg-reconfigure -plow unattended-upgrades

# 6. Configure VPN
sudo openvpn --config /etc/openvpn/client.conf

# 7. Enable Tor
sudo systemctl start tor
```

### **Privacy Configuration**

```bash
# 1. Disable telemetry
sudo systemctl disable ubuntu-report.service
sudo systemctl disable popularity-contest.service

# 2. Configure DNS (Cloudflare, Quad9)
sudo nano /etc/resolv.conf
# nameserver 1.1.1.1
# nameserver 9.9.9.9

# 3. Enable HTTPS everywhere
# Firefox: about:config → security.ssl.require_safe_negotiation = true

# 4. Configure privacy browser
firefox --new-window about:preferences#privacy
```

## 🔓 **CYBERSECURITY TOOLS USAGE**

### **Network Scanning**

```bash
# Scan network
nmap -sV target.com

# Aggressive scan
nmap -A -T4 target.com

# UDP scan
nmap -sU target.com

# Fast scan
masscan -p0-65535 target.com
```

### **Web Testing**

```bash
# SQL injection testing
sqlmap -u "http://target.com/page?id=1" --dbs

# Directory brute-forcing
gobuster dir -u http://target.com -w /usr/share/wordlists/dirb/common.txt

# Web fuzzing
wfuzz -c -z file,wordlist.txt http://target.com/FUZZ
```

### **Password Cracking**

```bash
# Identify hash type
hashid hash.txt

# Crack with Hashcat
hashcat -m 1000 hash.txt wordlist.txt

# Brute-force SSH
hydra -l admin -P wordlist.txt ssh://target.com
```

### **Reverse Engineering**

```bash
# Analyze binary
ghidra binary

# Use Radare2
radare2 binary

# Extract strings
strings binary | grep -i password
```
