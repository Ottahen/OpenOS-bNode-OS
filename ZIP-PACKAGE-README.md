## 🔨 Build Instructions

### Option 1: Build from Source (30-60 minutes)

```bash
# Extract files
unzip OpenOS-bNode-Complete-Package.zip
cd OpenOS-bNode-Complete-Package

# Build OS
sudo bash build-openos.sh

# Output: openos-bnode.iso (bootable ISO file)
```

### Option 2: Docker Build (10-20 minutes)

```bash
# Build Docker image
docker build -f Dockerfile.openos -t openos-bnode:1.0 .

# Run container
docker run -it openos-bnode:1.0 bash
```

### Option 3: Download Pre-Built ISO

```bash
# Download from official release
wget https://releases.openos-bnode.dev/openos-bnode-1.0.0.iso

# Verify checksum
sha256sum -c openos-bnode-1.0.0.iso.sha256
```

5. Reboot and enjoy!

### Virtual Machine (Safest)

3. Boot from ISO
4. Follow installer
5. Use in VM immediately

### Docker (Fastest)

2. Run container
3. Start using immediately
4. No installation needed
